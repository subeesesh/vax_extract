vaxextract pipeline

One vet vaccination document in, one client JSON out. Every entry point calls pipeline.extract_bytes; the requested vaccine names arrive with each request, and nothing in the code knows vaccine names.

OCR & layout (your module) LLM & mapping (others, paid API) Deterministic rules The product

Where the time goes

  • Band 1 (ingest + OCR + layout): about 2 s per document, logged as meta.ocrSeconds.
  • Band 2: the model generates in about 2 s but can wait 5–70 s for its first token. The hedged resend races a second request after 10 s.
  • Text-layer PDF pages skip preprocess and OCR entirely.

Review flags come from

  • Band 3 rules: unparseable or future given dates, names outside the request, missing pet name, no events.
  • Coverage check: a dated line that names a requested vaccine but produced no event.
  • Any flag sends the document to the fallback tier, when one is configured.

Configuration

  • VAX_LLM_*: primary model, base URL, key, reasoning effort, hedge seconds.
  • VAX_FALLBACK_MODEL, VAX_FALLBACK_VISION: optional escalation tier.
  • VAX_OCR, VAX_DEFAULT_DATE_ORDER, VAX_SHEET, VAX_EXPANSION_CACHE.
